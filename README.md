<img width="974" height="462" alt="image" src="https://github.com/user-attachments/assets/3bce47fd-e2c0-4c73-a408-f0a7a4d1b53c" /># Дипломный проект: Веб-сервис для рекомендации фильмов на основе семантического анализа пользовательских отзывов и предпочтений с применением NLP

Данный проект представляет собой веб-приложение, которое анализирует текстовые отзывы пользователей с помощью методов обработки естественного языка (NLP), формирует гибридный профиль предпочтений и выдает персонализированные рекомендации.

## Стек технологий

- Бэкенд: Python 3.10+, FastAPI, Uvicorn, SQLAlchemy (SQLite), Pandas, NLTK / Transformers
- Фронтенд: React 18, JavaScript, Axios, React Router
- NLP: сегментация текста, анализ тональности, выделение именованных сущностей

## Системные требования

- Операционная система: Windows 10/11, macOS, Linux (Ubuntu 20.04+)
- Python версии 3.10 или выше
- Node.js версии 18 или выше

## Быстрый старт

### 1. Клонирование / распаковка

Скопируйте папку `ПО` на свой компьютер. Откройте терминал (командную строку) в корневой папке `ПО`.

### 2. Настройка переменных окружения

В корневой папке создайте файл `.env` на основе образца `.env.example`:

copy .env.example .env # для Windows
cp .env.example .env   # для Linux/macOS

Отредактируйте `.env`.

### 3. Установка и запуск бэкенда
#### 3.1 Создание виртуального окружения Python

Перейдите в папку `backend`:

cd backend

Создайте виртуальное окружение:

python -m venv venv   # для Windows
python3 -m venv venv  # для Linux/macOS

Активируйте окружение:

venv\Scripts\activate     # для Windows
source venv/bin/activate  # для Linux/macOS

#### 3.2 Установка зависимостей

Вернитесь в корневую папку `ПО` и установите зависимости:

pip install -r requirements.txt

#### 3.3 Загрузка тестовых данных

В папке `scripts` находится скрипт `ingest_movies.py`. Он создает базу данных SQLite и заполняет её тестовыми данными. Запустите его:

cd scripts
python ingest_movies.py
cd ..

#### 3.4 Запуск сервера бэкенда

Находясь в корневой папке `ПО` с активным виртуальным окружением, выполните:

uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000

Вы должны увидеть сообщение:

INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Application startup complete.

Важно: Не закрывайте этот терминал – бэкенд должен работать всё время, пока вы используете приложение.

### 4. Установка и запуск фронтенда
#### 4.1 Переход в папку frontend

Откройте новый терминал (не закрывайте терминал с бэкендом) и перейдите в папку `frontend`:

cd frontend

#### 4.2 Установка зависимостей

npm install

#### 4.3 Запуск фронтенда

npm start

Через несколько секунд откроется браузер с адресом http://localhost:3000 (или вы сами перейдите по этому адресу).

### 5. Работа с приложением

1. На главной странице вы увидите список рекомендаций для текущего пользователя.
2. Вы можете:
   - Оставлять текстовые отзывы – система проанализирует тональность и выделит сущности, обновив ваш профиль.
   - Просматривать свой профиль – какие сущности вам нравятся, история оценок.
   - Получать обновлнные рекомендации – после взаимодействия рекомендации обновятся.
3. Все действия сохраняются в базу данных и влияют на рекомендации в реальном времени.

### 6. Остановка приложения

- Бэкенд: нажмите `Ctrl + C` в терминале, где запущен Uvicorn.
- Фронтенд: нажмите `Ctrl + C` в терминале, где запущен `npm start` (подтвердите `Y` при запросе).
